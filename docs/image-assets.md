# Image assets: provenance and pipeline

Every raster image served by the site is generated from an original in `assets-source/` by `npm run images` (sharp), following the manifest in `src/media/images.ts`. `public/` holds only generated output plus the few hand-made vector or document files listed below. Originals never ship.

## Pipeline

1. Put the original in `assets-source/` (PNG, JPEG or WebP, largest size available).
2. Describe it in `src/media/images.ts`: source path, output base name, the widths to render, the intrinsic size of the largest variant and, if needed, a crop in source pixels.
3. Run `npm run images`. It renders `public/<out>-<width>.webp` at quality 80, removes stale variants and fails if the manifest size does not match the rendered one.
4. Reference it from a component with `imageProps("<key>", sizes)`, where `sizes` describes the layout width at each breakpoint. Commit the generated files together with the manifest.

Rendered widths cover 1× to 3× device pixel ratios for the largest layout slot; browsers pick the smallest sufficient variant through `srcset`/`sizes`.

## Clips in `public/media/`

Short muted clips (`preload="none"`, a manifest image as poster, one MP4 source), played on the cards when they are reached and stopped by a click, by Enter or by scrolling on; They are not part of the image pipeline. Each one is a recording of the project itself, set up for this page and reproducible from the repository it belongs to.

## Rules

- Every cover is a screenshot, a rendering of the project's own artefacts or a frame of a recording, and the binding in `src/media/bindings.ts` names the file. A generated image, if one is ever used again, must be labelled “Concept illustration” and never presented as a product screenshot.
- Third-party material carries its licence next to it (SRS: MIT file; paper: CC BY 4.0 link) and a link to the original.
- Decorative images use `alt=""`; informative ones describe what the image documents (see the `alt` fields in `src/content/srs.ts`).
- The build budget is 1.5 MB for the static output without `media/`, plus 2 MB for the clips (`scripts/performance.mjs`); check it after adding images, and see `docs/content.md` before adding video.
